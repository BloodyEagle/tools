The script searches for installed JetBrains IDEs, looks for the KiloCode agent in them, and patches the UI, making the Reasoning blocks taller. It’s impossible to read the blocks by default — only 5 lines of text fit.

Скрипт ищет установленные IDE JetBrains, ищет в них установленный агент KiloCode и патчит UI, делая блоки Reasoning более высокими. В блоках по умолчанию читать невозможно - умещается всего 5 строк текста.
